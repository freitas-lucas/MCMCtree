MCMCtree-focused examples

This directory keeps examples that are useful for MCMCtree workflows:

- `DatingSoftBound/`: divergence-time example with soft bounds.
- `TipDate.FluH1/` and `TipDate.HIV2/`: tip-dating examples.
- `dating-cross-bracing/`: cross-bracing example.
- `ndata/`: multiple-partition approximate-likelihood examples.
- `combine-mcmc/`: example files for combining MCMC logs.
- `abglobin.aa` and `abglobin.trees`: small protein dataset useful for
  approximate-likelihood/protein model tests.
- `mcmctree.ctl`: top-level MCMCtree control-file example.

General PAML examples for programs outside the retained MCMCtree-focused
toolchain have been removed from this repository.
